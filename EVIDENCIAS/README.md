# Evidencias – Infraestructura 2

Esta carpeta corresponde a las evidencias obtenidas durante la
implementación y las pruebas de la Infraestructura 2.

Las evidencias documentadas incluyen:

- Topología FortiGate + Cisco.
- Direccionamiento de las interfaces.
- Configuración de la red USER y SERVER.
- VLAN 10 y DHCP.
- Configuración de la VPN IPsec.
- ACL de tráfico interesante.
- Enrutamiento entre las redes.
- Pruebas de conectividad.
- Estados de negociación IKE/IPsec.
- Troubleshooting realizado durante la práctica.

Las capturas completas y su explicación se encuentran incluidas
en la documentación técnica del repositorio.
